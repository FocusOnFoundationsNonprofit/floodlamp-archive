# FloodLAMP archive (public)

This repository holds the **AI-ready FloodLAMP archive**: markdown conversions of historical materials from FloodLAMP Biotechnologies (2020–2023), organized by category and subcategory, plus combined markdown rollups, zip bundles, and machine-readable indexes. The canonical copy is maintained from a private corpus and published here for open access.

**Organization:** Focus on Foundations (nonprofit). This publication is offered as a public good and as part of grant deliverables. The operating company is no longer active; this is a **closeout** archive, not an ongoing product.


## What is in this repo

- **`guides/`**, **`pilots/`**, **`regulatory/`**, **`various/`** — Category folders with subcategory markdown, metadata, combined files, and zip archives where applicable.
- **Top-level indexes and rollups** — Files such as `_categories.md`, combined views, and whole-archive zips at category or repo root as published from the internal corpus.
- **`_code/`** (optional) — Reference scripts and Webflow-related assets used to build, publish, and mirror this archive. See [`_code/README.md`](_code/README.md). This folder is populated by the mirror script when code mirroring is enabled; it is **not** required to read or use the archive markdown.


## How to use the archive

- **Chat-style AI:** Use subcategory or category **combined markdown** files (token counts often appear in filenames) in a single context window, together with audience/summary companion docs if present in the repo.
- **Agentic tools:** Download **zip** bundles (subcategory, category, or full archive), unpack locally, and point your agent at the folder for multi-file search and synthesis.

See also the project’s public-facing site for navigation and context: [floodlamp.bio](https://www.floodlamp.bio).
